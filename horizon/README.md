# Horizon

A quarterly note on what is changing in data and security, and what that means for what
I should be learning next. One file per quarter. Fifteen minutes to read, an afternoon
to write, and it is the difference between learning the field as it was and as it is.

## Method

1. Read the release notes of five tools I actually use. Not blog posts about them.
2. Read two vendor engineering blogs and two independent practitioners.
3. Read one job-market signal: what are the roles I want actually asking for this quarter,
   compared with the same search last quarter?
4. Write the file below. Include what I got wrong last quarter.
5. Decide one thing to add to the module queue, and one thing to stop tracking.

The fifth step is the one that matters. A horizon review with no change to the queue is
entertainment.

## Rule

Distinguish three things and label them in every entry:

- **Happening** — in production at companies now.
- **Consolidating** — clearly winning, still early.
- **Noisy** — loud, unproven, might be nothing.

Most people's career mistakes come from treating category three as category one.
